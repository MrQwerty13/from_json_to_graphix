# json-graphix-analitic

Small Flask app that reads a JSON file, normalizes it for analysis, creates simple graphs, and serves results.

Usage:

1. Create virtual environment and install deps:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

2. Run the app:

```bash
python app.py
```

3. Open http://127.0.0.1:5000 and upload a JSON file.
